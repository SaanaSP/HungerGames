Personal old school Hunger Games plugin 🤗

`/start hunger` to begin, with `/start hunger mayhem` as an extra option

`/end` to end early, clears up all runnables (I hope)

`/set head <id>` to change the golden head texture

`/debug` if you want a little look inside

`/invsee` to look inside someone's inventory - it isn't good, you can't edit it. But it was fun to make

`/heal` and `/feed` do what they say

`/teams` is like cool, if you do `/start bedwars`, where I was going to add bedwars to the same plugin, but I decided 1.21 had more fun features


Has a brief grace period and two zone changes. Zones use the worldborder so they're a little clunky. I wanted to get something working quick as I was losing interest at that time, so it is what it is.


Made inconsistently over the course of like a year. My discovery of ChatGPT came somewhere in between, seen in things like the custom head generator etc.
Might continue later, when I grow the courage to transition it to a Gradle project so I can use Kotlin.


Can be adjusted for any world in theory... if you feel like editing all of the chest coordinates and the constant zone maths and start positions 😁

The map was made by me and my friends. All the good parts made by them.
